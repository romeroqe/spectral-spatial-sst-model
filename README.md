# spectral-spatial-sst-model

[![Release](https://shields.io/github/v/release/romeroqe/spectral-spatial-sst-model)](https://github.com/romeroqe/spectral-spatial-sst-model)
[![License: GPL v3](https://img.shields.io/badge/License-GPLv3-blue.svg)](https://www.gnu.org/licenses/gpl-3.0)

This repository contains the implementation, processing workflows, and analysis scripts of a spectrally constrained, spatially explicit statistical ocean modeling framework for high-resolution reconstruction and prediction of sea surface temperature, which is associated with a scientific article currently under review.

## Installation
The Python package will be made available after publication. For now, users should download or clone this repository.

```bash
git clone https://github.com/romeroqe/spectral-spatial-sst-model.git
```

## Demo
To explore the demos, navigate to the `demo` folder and run the scripts as described.

## Datasets
The datasets generated in the study, including GAM skill, predictor maps with their dominant modes (period, amplitude, phase), as well as the hindcast and forecast, are publicly available in SEANOE at [https://www.seanoe.org/preview/113767?token=CmMgKwF35Xlpxtbl99kuc6BEDFgw41aZ](https://www.seanoe.org/preview/114395?token=A3HliZ68V9TqlWNe26DftJj6HdguJdNw).
